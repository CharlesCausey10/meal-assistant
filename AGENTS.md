# Agent Instructions

Before making changes in this repository, read `PROJECT_STRUCTURE.md`.

Use it as the first source of orientation for the app structure, data model, major files, and common change locations. If it appears stale or conflicts with the code, inspect the relevant source files and update `PROJECT_STRUCTURE.md` as part of the change.

After making changes in this repository, open up localhost:3000 to inspect and test the changes (and start the dev server if it isn't already running). If you change anything, make sure to change it back, because the dev data is my personal data.
